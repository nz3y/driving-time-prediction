Machine learning project to predict driving time using Python and scikit-learn
# Driving Time Prediction

## Project Overview
This project aims to predict driving time using machine learning.

## Objectives
- Explore and understand driving data
- Preprocess data for machine learning
- Train and compare regression models
- Evaluate prediction performance using Mean Absolute Error (MAE)

## Tools
- Python
- pandas
- scikit-learn
- Matplotlib / Seaborn

## Models
- Decision Tree Regressor
- Random Forest Regressor

## Status
Project setup in progress.
